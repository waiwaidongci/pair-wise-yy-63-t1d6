# pair-wise-yy-63 跨产品设计令牌治理与主题发布平台

维护基础令牌、语义令牌和组件别名，支持品牌主题、明暗模式与平台变体继承覆盖。包含令牌树、Monaco JSON 编辑、依赖图、循环引用与对比度校验、批量替换、变更评审、版本差异和发布锁定。

## 技术栈

Vue 3、TDesign、Pinia、Vue Router、TanStack Query、Axios、Monaco Editor、Vite、TypeScript。

## 运行

```bash
npm install
npm run dev
```

访问 `http://localhost:62063`。草稿、变更评审和发布批次对账数据保存在 `localStorage`。

## 发布批次可恢复对账（主题发布页）

回执不再只留在浏览器内存中，批次、写入尝试与回执全部随批次持久化：

- **创建批次即冻结**：冻结候选令牌与依赖解析快照（`tokenPackages[rev]`，含别名 → 基础值解析链），生成批次号 `PB-YYYYMMDD-NNN`。
- **回执按批次号 + 通道号合并**：通道序号严格单调；同一通道的重复回执（序号与内容指纹一致）只保留首次；**序号乱到**或**内容指纹不一致**（如产品侧仍拿旧别名）时双方回执全部留档，通道进入「待核」，人工可采纳先到/后到。
- **基础令牌改动 → 未闭合批次立即失效重算**：生成新修订 rev，未完成通道回到待发按新快照重发；**已确认通道不动**，仍可按确认时修订查看原快照，并列出与最新修订之间的「补发差异」。
- **写入失败可恢复**：批次和失败尝试都保留（失败也占序号），可立即重试；重试只针对未完成通道，已确认通道不再生成任何发包。全部通道确认后批次才能闭合。
- 控制台提供故障模拟：写入故障、关闭自动回执（手动补收，模拟刷新/重启恢复）、重复回执、乱序、内容篡改。
